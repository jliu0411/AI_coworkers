
# SJSU Agentic AI Coworkers

This project contains two AI agents designed to help students improve their technical skills and prepare for future career opportunities.

## Agents

### 1. DailyTechUpgradeAgent
- Finds three relevant technical articles daily.
- Summarizes articles and key takeaways.
- Recommends articles based on user interests and learning progress.

### 2. nextLevelPersonalCoachForCareerLevel
- Finds relevant career opportunities.
- Generates technical interview questions.
- Evaluates answers and identifies knowledge gaps.
- Tracks progress and recommends improvements.

## Technologies
- Python
- LangGraph
- Streamlit
- SQLite
- OpenAI API (optional)

## How to Run

1. Install the required packages:

```bash
pip install -r requirements.txt
```

2. Start the application:

```bash
streamlit run app.py
```

3. Open the application in your browser.

Select **Demo Mode** to test without an API key.

## Project Goal

Help students continuously improve their technical knowledge and prepare for future jobs, research, and entrepreneurial opportunities.
